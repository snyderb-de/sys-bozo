DEC-005

GUI app decisions

Classify apps as shared, Mini-only, MacBook-only, manual/private, or cleanup. The machines should differ by intent, not because old installers left fingerprints.

Decision key

Pick one target per app.

ChoiceMeaningConfig action
sharedInstall on both Macs.Declare in shared macOS app module when possible.
mini-onlyDesk hardware, display, server-ish, or Mini workflow.Declare in Mini host profile.
macbook-onlyLaptop/travel/workflow-specific.Declare in MacBook host profile.
manual/privateLicense, work auth, App Store, vendor account, or secret-ish setup.Document but do not auto-install yet.
cleanupOld, duplicate, or unused.Remove after confirmation.
