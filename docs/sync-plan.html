Policy

Sync Plan

The goal is not identical machines. The goal is identical intent: shared defaults everywhere, explicit host differences where reality demands it, and install profiles that do not require buying into every tool at once.

LayerAuthoritySync policy
CLI and TUI packagesNix profile or plain checklistShared baseline across selected hosts.
GUI appsHomebrew casks when enabledShared baseline plus explicit host-only additions.
Mac App StoreMAS-only BrewfileManual run until MAS is pulled into an apply flow.
Shell configHome Manager or shell installerShared, with private overrides in local files only.
SSH aliasesSOPS private configNever public. Decrypt into XDG config.
Host factsHOST_MATRIX.mdPublic only when not sensitive.

Order of operations

Short version: fix plumbing before adding ceremony.

0. Get Tailscale SSH working across all devices 1. Make dotfiles-audit compare canonical hosts 2. Import the sys-bozo CLI/TUI tools through Nix 3. Add iTerm2 through the optional Homebrew module 4. Define sys-bozo install profiles 5. Split flake.nix into hosts/ and modules/ 6. Add Linux profiles after the module boundaries are clean
Sync policy favors explicit drift over accidental drift.Updated
