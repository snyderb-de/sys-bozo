DEC-004

Brew CLI tool decisions

Decide each Homebrew leaf as shared baseline, Mini-only, MacBook-only, move-to-Nix, manual, or cleanup. Leaves are closer to intentional installs than the full formula list.

Decision key

Pick one target per item.

ChoiceMeaningConfig action
sharedShould exist on Mini and MacBook.Declare in shared profile, preferably Nix for CLI tools.
mini-onlyOnly the Mini needs it.Declare in Mini host profile.
macbook-onlyOnly the MacBook needs it.Declare in MacBook host profile.
move-to-nixUseful tool, wrong manager.Add to Nix/Home Manager, verify, then remove Brew copy.
manualInstall is tied to auth, vendor flow, or one-off work.Document as manual/private.
cleanupProbably old or accidental.Remove after confirming no current use.

Runtime version policy

DEC-013 and DEC-014 are the same issue: app projects need project-owned runtimes.

IDDecisionWhy
DEC-013Use Nix dev shells plus direnv as the default version-management model for Go and Node project work.Project runtime versions live with the project, work across Mac/Linux, and do not depend on global mutable state.
DEC-014Keep global Go and Node as shared convenience tools only.Useful for scratch commands and simple tooling, but app development should enter the project shell.
DEC-015Keep OpenJDK as-needed.Do not remove current installs blindly, but do not mark Java shared/global unless a project or workflow needs it.
